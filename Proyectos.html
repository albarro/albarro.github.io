Gusbabot

Repositorio

Un bot para Telegram escrito en TypeScript usando NodeJs y utilizando la librería node-telegram-bot-api

La principal filosofía detrás del bot fue que gran parte de su comportamiento fuera controlado por archivos externos y que permitieran poder adaptar el bot fácilmente a diferentes grupos e incluso permitir a usuarios no técnicos modificar el comportamiento del mismo.

Esto se realizo creando archivos de configuración en json y en el repositorio se encuentran archivos de ejemplo para cada uno

Para su funcionamiento se desplegó en Oracle Cloud con su tier gratuita, actualmente ya no esta desplegado por las limitaciones de la tier gratuita.

Free Car

Videojuego web desarrollado en Godot.

Pese a que aun este en desarrollo aqui puedes las versiones existentes:

  • V1, prototipo inicial
  • V2, se crea el sistema de movimiento del personaje principal
  • V3, se crea el sistema de colisiones con los obstáculos, asi como un perseguidor
  • V4, version actual, se crea una interfaz básica, menus de pausa y un nuevo "nivel", ERROR: En ocasiones no se cargan las texturas
